
# Data and code availability

The version-matched author-created code, derived data products, saved outputs,
protocols, manifests, and reproducibility materials supporting
*Receiver Provenance, Population Selection, and Reliability Trade-offs in RSSI Localization*
are archived under Zenodo version DOI:

`10.5281/zenodo.23083321`

The corresponding source repository is:

`https://github.com/anantarj/antwerp-lorawan-coordinate-provenance`

with release tag `v2.0.0`.

The archival concept DOI is `10.5281/zenodo.22143329`. The historical v1.0.0 release
remains available at `10.5281/zenodo.22703158`.

## Verification scope

Saved-output verification, contract testing, frozen replay, source
reconstruction, and complete experimental reexecution are distinct scopes.
Complete reexecution of externally grounded branches requires separately
obtained third-party inputs.
